# Onde subir cada imagem na Cakto

No painel: **Produtos → [produto] → imagem do produto**. Para os order bumps, a imagem é a do próprio produto do bump (ex.: "Bonés em Crochê — Receitas") e aparece no checkout quando "Exibir imagem" está ligado.

As ofertas de back redirect (oferta especial) ficam dentro dos produtos Kit/Premium e usam a mesma imagem deles.
